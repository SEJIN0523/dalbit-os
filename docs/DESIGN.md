# Dalbit 디자인 기준

화면 곳곳이 같은 OS처럼 보이도록 지키는 기준입니다. 새 위젯·아이콘·설정을 만들거나 바꿀 때 이 문서를 먼저 확인하고, 기준을 바꾸면 이 문서도 함께 고칩니다.

## 기본값

| 항목 | 기본 | 선택지 |
|---|---|---|
| 배치 | **맥식**: 위쪽 메뉴 막대 + 아래 독 | Windows식: 아래 작업표시줄 |
| 모양 | **라이트 (Mist)** | 다크 (Dusk) |
| 부팅 · 잠금 · 로그인 화면 | 항상 다크 | — |

- 새 기능과 다듬기는 **맥식 + 라이트에서 먼저 완성**하고, 그다음 다크와 Windows식에서 깨지지 않는지 확인합니다.
- 기본값은 `build_files/build.sh`의 2-4절에서 정합니다. 바꿀 때는 `dalbit-theme`과 `cc-status`의 대체값, 워크플로의 이미지 검사도 같이 바꿉니다.

## 색

색의 원본은 `tools/gen-color-schemes.py`입니다. 값을 바꾸면 스크립트를 다시 실행해 `.colors` 파일을 만들고, 한글 입력기(`tools/gen-fcitx5-themes.py`)와 터미널 색도 맞춥니다.

| 역할 | 라이트 (Mist) | 다크 (Dusk) |
|---|---|---|
| 창 바탕 | `#eef0f3` | `#1e2024` |
| 내용 바탕 (목록 · 입력창) | `#ffffff` | `#191b1f` |
| 버튼 | `#e2e5ea` | `#2a2d33` |
| 글자 | `#1e2127` | `#eceef2` |
| 흐린 글자 | `#6b717c` | `#959ba6` |
| **강조** | `#5f77ae` 차분한 파랑 | `#a9b8d8` 연한 하늘색 |
| 경고 · 주의 · 완료 | `#c2414e` · `#a87a12` · `#2e8a57` | `#e5707a` · `#d9c28a` · `#7ccb9c` |

- 강조색은 **한 가지만** 씁니다. 선택된 항목, 켜진 스위치, 포커스 표시에만 쓰고 장식으로 넓게 칠하지 않습니다.
- 위젯(QML)에서는 색을 직접 적지 않고 `Kirigami.Theme`의 색을 씁니다. 그래야 다크·라이트 전환에 저절로 따라옵니다.
  - 예외: 컨트롤 센터와 시작하기 창의 **모양 미리보기 타일**은 반대쪽 모양을 보여줘야 하므로 고정 색을 씁니다.

## 글꼴

| 용도 | 글꼴 |
|---|---|
| 화면 전체 | Pretendard 10pt (보통 굵기) |
| 가장 작은 글자 | Pretendard 8pt |
| 창 제목 | Pretendard 10pt, 굵기 500 |
| 패널 제목 (예: 컨트롤 센터 맨 위 "Dalbit") | 기본 크기 × 1.15, DemiBold |
| 터미널 · 코드 | D2Coding 10pt |

- 크기는 숫자로 고정하지 않고 `Kirigami.Theme.defaultFont`와 `smallFont`를 기준으로 키우거나 줄입니다.
- 보조 설명은 작은 글꼴 + 흐리게(불투명도 0.65)로 통일합니다.

## 모서리와 간격

- 간격과 둥글기는 `Kirigami.Units`(smallSpacing, largeSpacing, gridUnit)로만 정합니다. 화면 배율이 바뀌어도 비율이 유지됩니다.
- 카드와 버튼 모서리: `Kirigami.Units.smallSpacing` (기본 배율에서 약 4px).
- 동그란 요소(창 버튼, 상태 점, 달 아이콘)는 완전한 원으로 만듭니다.

## 패널

| | 위치 | 높이 | 떠 있음 |
|---|---|---|---|
| 맥식 메뉴 막대 | 위 | gridUnit × 1.6 | 아니요 (화면에 붙음) |
| 맥식 독 | 아래 가운데, 앱 수만큼 | gridUnit × 3.4 | 예 |
| Windows식 작업표시줄 | 아래 | gridUnit × 2.6 | 예 |

- 시스템 트레이에는 Wi-Fi · 소리 · 배터리만 보이게 합니다(`tray-tidy`). 나머지는 펼쳤을 때만 보입니다.

## 창

| | 맥식 | Windows식 |
|---|---|---|
| 창 장식 | Dalbit 동그란 버튼 (Aurorae `DalbitMacLight` / `DalbitMac`) | KDE 기본 (Breeze) |
| 버튼 | 오른쪽: 최소화 · 최대화 · 닫기 (`dalbit-theme --buttons-left`로 왼쪽 맥 순서) | KDE 기본 |
| 테두리 | 없음 (크기 조절은 창 바깥 보이지 않는 영역) | KDE 기본 |
| 제목 | 가운데 정렬, 제목 표시줄 높이 36px | KDE 기본 |
| 애니메이션 | 120ms | KDE 기본 |

창 장식 SVG는 `tools/gen-mac-decorations.py`로 만듭니다. 직접 고치지 않습니다.

## 아이콘

- **앱 아이콘**: 64×64 격자에 둥근 사각형 바탕(모서리 반경 17, 1px 외곽선) + 가운데 선 아이콘. 선 아이콘은 24 격자에서 굵기 1.45, 끝과 모서리는 둥글게.
- **폴더 아이콘**: 강조색 계열 두 톤 폴더 + 흰 선 기호(굵기 2.2). `tools/gen-folder-icons.py`로 만듭니다.
- 다크·라이트 두 세트를 항상 함께 만듭니다. 한쪽에만 있는 아이콘은 다른 쪽에서 KDE 기본 아이콘으로 섞여 보입니다.

## 바꾼 뒤 확인할 화면

라이트 · 맥식에서 먼저, 다음으로 다크와 Windows식에서:

1. 메뉴 막대: 달 메뉴, 앱 이름, 트레이, 시계와 달력
2. 독과 컨트롤 센터(모양 · 전원 · 자원 · 휴대폰 · 업데이트)
3. 파일 탐색기, 시스템 설정, 터미널의 창 버튼과 제목 표시줄
4. 한글 입력기 후보 창
5. 시작하기 창(`plasmawindowed org.dalbit.welcome`)
