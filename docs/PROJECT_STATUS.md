## 지금 단계

**6단계: 일상 사용하며 개선.** 노트북에 Dalbit 이미지를 설치해 쓰면서, 실사용 피드백으로 작업표시줄·컨트롤 센터·배치를 다듬고 있습니다. 최근 작업은 맥식 배치(위쪽 메뉴 막대 + 독, 오늘의 달 메뉴, 동그란 창 버튼)입니다.

## 확인 상태

아래에서 **확인**은 실제로 동작을 본 것, **확인 필요**는 아직 기록이 없는 것입니다.

## 빌드 참고

- 빌드 실패는 대개 바로 다음 커밋에서 고쳐졌습니다. 실패가 나면 Actions 로그의 "이미지 검사" 단계를 먼저 봅니다.
- 설치 ISO 아티팩트(약 5.5GB)는 30일 보관이며, 현재 파일은 **2026-12-06에 만료**됩니다. 필요하면 Actions → Build Dalbit ISO → Run workflow로 다시 만듭니다.
- 현재 ISO는 브랜딩 이전 이미지로 만들어져 설치 화면에는 Dalbit 브랜딩이 없습니다. 설치 후 업데이트로 최신 이미지가 적용됩니다.
